# VKclone

Учебный проект — визуальный клон страницы профиля ВКонтакте.

## Что реализовано

- адаптивная трёхколоночная компоновка страницы;
- шапка и боковая навигация в стиле VK;
- профиль с обложкой, аватаром, музыкой, информацией и действиями;
- описание профиля без JavaScript-генерации;
- галерея из локальных фотографий проекта;
- блок создания публикации и пост с комментариями;
- правые информационные карточки: подписчики, друзья, подарки и подписки;
- ссылки на реальные сообщества VK;
- мобильное меню с затемнением фона.

## Технологии

- HTML5
- CSS3
- JavaScript
- SVG

## Структура проекта

```text
VKclone/
├── example/          # Примеры и скриншоты исходной страницы
├── images/           # Локальные изображения профиля, поста и галереи
├── index.html        # Разметка страницы
├── style.css         # Основные стили и адаптивность
├── script.js         # Только логика мобильного меню
└── README.md         # Описание проекта
```

## Запуск

Проект не требует сборщика.

Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages.
