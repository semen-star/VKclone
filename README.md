# VKclone

Учебный проект по лабораторной работе №2 по HTML/CSS.

## О проекте

VKclone — адаптивная статическая страница профиля, выполненная по образцу профиля во «ВКонтакте».

Проект предназначен для демонстрации навыков:

- семантической разметки HTML5;
- стилизации с помощью CSS3;
- построения адаптивного интерфейса;
- работы с изображениями и SVG;
- создания структуры страницы, похожей на современный интерфейс социальной сети.

## Реализовано

- шапка сайта с логотипом и поиском;
- боковая навигация;
- профиль пользователя Семёна Старикова;
- обложка и аватар профиля;
- музыкальный блок;
- описание профиля;
- фотографии;
- публикация на стене и комментарии;
- блоки друзей и сообществ;
- ссылки на сообщества во «ВКонтакте»;
- адаптация интерфейса под разные размеры экрана;
- мобильное боковое меню.

## Технологии

- HTML5
- CSS3
- JavaScript
- SVG

## Структура проекта

```text
VKclone/
├── example/          # Примеры/скриншоты исходной страницы
├── images/           # Изображения профиля и публикаций
├── index.html        # Основная страница
├── style.css         # Стили страницы
├── script.js         # JavaScript-логика
└── README.md         # Описание проекта
```

## Запуск

Проект не требует сервера или сборщика.

Откройте `index.html` в браузере или разместите репозиторий на GitHub Pages.
